# 공동 마음세탁소

한 화면에서 아바타를 움직이며 걱정을 빨고, 다른 방문자와 따뜻한 말을 주고받는 24시간 셀프 빨래방입니다. 2.5D 아이소메트릭 캔버스 하나로 만든 단일 파일(`index.html`) 웹 앱이라 빌드 과정이 없습니다.

## 실행

- `index.html`을 웹에 올리면 됩니다. GitHub Pages: 저장소 Settings → Pages → Branch `main` / `(root)`.
- 파일을 그냥 더블클릭해서 열어도 되지만, 다른 사람과 만나려면 인터넷에 열려 있어야 합니다.

## 여러 명이 모이는 방법 (Trystero)

[Trystero](https://github.com/dmotz/trystero)(WebRTC P2P)로 **서버 없이** 같은 방 이름끼리 바로 연결됩니다.

- 처음 열면 `lobby` 방에 들어갑니다. 같은 주소를 연 사람들은 같은 세탁소에서 만납니다.
- 친구끼리만 모이려면 `?room=우리모임` 처럼 주소 뒤에 방 이름을 붙이거나, 도움말(?)의 방 이름 칸에서 이동 후 **초대 링크 복사**를 누르세요.
- 상태(위치, 대화, 세탁기 사용)는 접속한 사람들끼리 직접 주고받고 어디에도 저장되지 않습니다. Trystero는 처음 서로를 찾을 때만 공개 Nostr 릴레이를 씁니다.
- 라이브러리는 실행할 때 jsDelivr에서 `trystero@0.26.0`을 받아 옵니다. 받지 못하면 혼자 체험 모드로 동작합니다.

### 알아 둘 점

- 사람이 많아지면 서로 직접 연결(메시)이라 무거워집니다. 한 방에 10~15명 이하를 권장하고, 앱은 한 화면에 최대 24명까지만 그립니다.
- 회사·학교망, 일부 통신망에서는 직접 연결이 막힐 수 있습니다. 그럴 때는 `index.html`의 `TURN` 배열에 TURN 서버를 넣으세요(`[{urls:'turn:...',username:'...',credential:'...'}]`).
- 연결된 사람끼리는 WebRTC 특성상 서로의 IP 주소가 전달될 수 있습니다. 방 이름은 누구나 짐작할 수 있으니 비공개 장소가 아닙니다.
- 낯선 사람과 쓰는 공개 방에는 자유 대화가 있습니다. 전화번호·메신저 ID 같은 연락처는 보내기 전과 받을 때 모두 걸러지고, 사람별로 숨길 수 있습니다. 공개 서비스로 운영한다면 이용 안내와 신고 방법을 따로 갖추세요.
- Claude에서 공유한 링크로 열면 Trystero 대신 Claude의 실시간 기능으로 연결됩니다(로그인한 사람끼리). Claude 안에서는 WebRTC가 막혀 있어서입니다.

## 하는 일

- 걷기: 바닥을 누르거나 끌기(모바일), 방향키·WASD(PC). `E` 키로 가까운 물건 사용
- 세탁 → 건조 → 개기 흐름, 휴게실(소파·차·응원 게시판)
- 준비된 문장과 최대 80자 자유 대화, 연락처 입력 차단, 사람별 숨기기
- 동물 8종 3D 캐릭터(걷는 방향 따라 몸·얼굴이 돌아가고 숨 쉬고 눈 깜빡임)

## 구조

단일 `index.html` 안에 스타일, 캔버스 렌더러(깊이 정렬·A* 길찾기·카메라), 게임 로직, 채팅 안전 필터, 실시간 연결 계층이 모두 들어 있습니다. 실시간 연결은 `presence` 하나로 단순하게 맞춰 두어, Claude room과 Trystero를 같은 코드로 씁니다.
