# 공동 마음세탁소

한 화면에서 아바타를 움직이며 걱정을 빨고, 다른 방문자와 따뜻한 말을 주고받는 24시간 셀프 빨래방입니다. 2.5D 아이소메트릭 캔버스 하나로 만든 단일 파일(`index.html`) 웹 앱이라 빌드 과정이 없습니다.

## 실행

- `index.html`을 브라우저에서 열면 됩니다.
- GitHub Pages: 저장소 Settings → Pages → Branch `main` / `(root)`를 고르면 주소가 생깁니다.

## 하는 일

- 걷기: 바닥을 누르거나 끌기(모바일), 방향키·WASD(PC). `E` 키로 가까운 물건 사용
- 세탁 → 건조 → 개기 흐름, 휴게실(소파·차·응원 게시판)
- 준비된 문장과 최대 80자 자유 대화, 연락처 입력 차단, 사람별 숨기기
- 동물 8종 3D 캐릭터(걷는 방향 따라 몸·얼굴이 돌아가고 숨 쉬고 눈 깜빡임)

## 접속 방식

- 일반 웹(이 저장소를 그대로 호스팅): **혼자 체험 모드**. 가상 손님과 함께 지냅니다.
- Claude에서 공유한 링크로 열기: Claude에 로그인한 사람끼리 `room` 기능으로 **실시간 다중 접속**이 됩니다. (이 기능은 Claude 안에서만 동작합니다.)
- 일반 웹에서 실시간 다중 접속이 필요하면 Supabase Realtime 같은 서버 연결을 추가해야 합니다. 이때 공개용 anon key만 쓰고 service_role/secret key는 코드에 넣지 마세요.

## 구조

단일 `index.html` 안에 스타일, 캔버스 렌더러(깊이 정렬·A* 길찾기·카메라), 게임 로직, 채팅 안전 필터가 모두 들어 있습니다.
